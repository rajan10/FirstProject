# Loan Approval Classification Project

## Dataset
`loan_approval_dataset.csv` contains 614 loan applications with demographic,
financial, credit-history, property-area, and loan-term features.

Target:
- `Loan_Status = Y` -> Approved
- `Loan_Status = N` -> Rejected

## Suggested project files
- loan_approval_dataset.csv
- loan_approval_classification.py
- requirements.txt

## Install
pip install -r requirements.txt

## Run
python loan_approval_classification.py

## Educational note
This dataset is prepared for an educational machine-learning assignment.
It should not be used for real lending decisions.
